# Glossary

| Term | Meaning |
| --- | --- |
| Allowlisted metric | A derived field the API will persist; see Derived Metrics Allowlist |
| Bitmask | Packed set test for equipment, position, or constraint tokens |
| Caution | Eligible exercise with a documented limitation |
| Event bus | In-process, non-durable motion event channel |
| Feature | Angle, velocity, ROM, stability, or confidence scalar |
| Guest mode | On-device SQLite planner and history; no API required |
| Live mode | Supabase Auth plus Fastify, publishable key only |
| Local orchestrator | On-device component that emits validated tool calls (<125M params) |
| Native inference | Pose samples produced by the AdaptFit pose module |
| Recipe | Per-exercise angle targets, laterality, and issue vocabulary |
| Tool call | Schema-validated side effect requested by the orchestrator |
| Tracking off | Camera unused; session continues with manual or timed counts |
